## Before you submit the camera-ready

1. Read `REVIEW_RESPONSE.md`: every review point and what changed.
2. The repository link in the introduction points to the tag `midi2026`. Create and push
   that tag at the final commit, or the link returns 404.
3. Decide on an LLM-use statement in the acknowledgments. Springer's AI policy asks for one,
   and it is not in the paper.
4. After any edit, recompile and keep the paper at **8 pages or fewer, references included**.
   It is full: page 8 has only a few lines to spare, so any addition needs a matching cut.
5. Upload the final PDF and sources as the organizers instruct, by 29 Nov. Send the video
   link to midi@opi.org.pl the same day. Slides are in `../presentation/`.

The closed-loop numbers (Table 2, Fig. 4b) come from the camera-ready campaign:
`nav/tools/run_camera_ready.sh`, scored by `nav/tools/camera_ready_table.py`. The summary is in
`nav/results/camera_ready/campaign_cr_2026-11-21.txt`.

## Compile

**Overleaf**: upload `../qvla_paper_overleaf.zip` as a new project. Use the default compiler (pdfLaTeX); it runs BibTeX automatically.

**Locally**:

```bash
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

This machine's TeX Live lacks two packages that Overleaf has. `newtx` was installed to a
private texmf tree. TeX Gyre's TS1 metrics (Debian `texlive-fonts-extra`) are needed by the
`·` between keywords. Without them pdflatex stops with ``Font TS1/ntxtlf/m/n/9=ts1-qtmr …
not loadable``. The paper sources are not the cause: the template's own `samplepaper.tex`
(which also uses `newtxtext`) asks for the same missing `ts1-qtmr` here and exits with status 1. `main.pdf` in this directory was built with a
preview-only font mapping to txfonts' Type 1 Times companion. All fonts are embedded; there
are no Type 3 fonts.

## Figures

All four figures are drawn at their printed size from the repository's own data by one script:

```bash
python3 scripts/make_figures.py            # all four
python3 scripts/make_figures.py qual       # or: overview | menu | qual | results
```

Every number in the text, tables and captions was taken from the recorded runs and probes
documented in the repository's `CLAUDE.md` and `nav/`. Follow the same rule when editing:
check a number against its raw source, not against a summary.
