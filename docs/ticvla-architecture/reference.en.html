TIC-VLA

A two-rate navigation policy: a 1.9 B vision-language model thinks slowly about delayed frames and leaves its attention state behind; a 10.3 M cross-attention head reads that state and emits 30 waypoints at 10 Hz. Every dimension below was read out of the code and checked against the shipped checkpoint.

03 Losses

Two stages, two losses, and they never meet. There is no joint objective anywhere in the codebase — no weighted sum, no alternating schedule.

Stage 1 — language loss

# ticvla/models/vlm.py — InternVL's own causal-LM head language_loss = CrossEntropy(logits[..., :-1, :], labels[..., 1:]) # ticvla/data/vlm_data.py — mask everything before the answer turn labels = input_ids.clone() sep_id = tokenizer.convert_tokens_to_ids('assistant') start_idx = first position where labels[i] == sep_id labels[i, :start_idx] = -100 # system + user + images ignored

The supervised target string, built per sample:

<think> {Chain of Thought Reasoning} </think> <answer>(x₃, y₃, θ₃), (x₆, y₆, θ₆), (x₉, y₉, θ₉)</answer> # from the DELAYED frame's future, in delayed-frame coordinates # indices 29 / 59 / 89 at 10 Hz -> 3 s, 6 s, 9 s θ = atan2(y, x + 1e-3) # redundant: it is just the pair's own bearing

Stage 2 — action loss

# ticvla/training/train.py — this is the entire objective action_loss = F.smooth_l1_loss(predicted_waypoints, target_waypoints) total_loss = action_loss # Huber, beta = 1.0, reduction = 'mean' over (B, 30, 2) # 0.5 (p - t)^2 if |p - t| < 1 # |p - t| - 0.5 otherwise # reported, never optimised: ADE = ‖p - t‖₂.mean() # average displacement, all 30 steps FDE = ‖p - t‖₂[:, -1].mean() # final displacement, step 30 only

The gap this leaves

TICVLA.forward returns a language_loss that stage 2 never reads. With train_vlm=False the VLM's parameters have requires_grad=False, the KV cache is .detach()ed, and extract_feature runs under no_grad. Three independent barriers, so the returned value is a zero tensor that is dropped on the floor.

The consequence is structural: no action error ever reaches the VLM. The language model is optimised purely to write plausible waypoint text at 3/6/9 s, and the action expert is optimised purely to fit trajectories given a state it cannot influence. Whatever steering competence lives in the network as a whole was learned by 10.3 M parameters reading a frozen 128-dimensional summary.

04 Targets and the delay mechanism

The delay is not an artefact being tolerated — it is sampled on purpose, and it is what the two branches are asked to reconcile.

# per training sample, ticvla/data/policy_data.py max_delay = min(10.0, current_time) τ = max_delay * np.random.rand() # uniform, fresh every __getitem__ files_back = int(τ / 0.1) # the corpus is 10 Hz # the VLM sees the frame stack ending at t - τ # the action expert sees the frame at t # and is told how far the robot moved in between: dx, dy = delayed_frame.future[round(τ * 10)].offset[:2]

So robot_state[3:5] is a delay-compensation channel: it tells the head how stale the thinking it is reading actually is. The action targets themselves are unconditional — 30 cumulative (dx, dy) offsets straight out of the current frame's future list, zero-filled if the episode ends early.

previous_waypoints_text, fed to the VLM as prose, is built by integrating history at 1 Hz with a running yaw: Δθ = 2·atan2(dy, dx + 1e-6) accumulated and wrapped to ±π. It is the only place the network is told its own recent motion in words.
